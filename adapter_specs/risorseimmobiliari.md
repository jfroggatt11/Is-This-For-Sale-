# RisorseImmobiliari — reviewed 2026-09-14

Operator: BasicSoft S.r.l.; agency portal across Italy. Decision: integrate bounded
public factual searches. No API key, login, or feed agreement used.

Primary evidence:
- https://www.risorseimmobiliari.it/ links province residential sale catalogues.
- https://www.risorseimmobiliari.it/Firenze/case_in-vendita_Firenze.html returned
  HTTP 200 with 7,865 residential sale advertisements, 18 per page, on review.
- Pagination links preserve the province and `cod_categoria=R`, with `_pag2.html`.
- Public detail pages expose labeled contract, type, municipality, price, surface,
  bedrooms, source date and property-map coordinates in HTML microdata.
- https://www.risorseimmobiliari.it/robots.txt allows those paths but disallows
  `/cerca_immobili.asp`, `/include/`, imports and print pages. Never use those paths.
- https://www.risorseimmobiliari.it/privacy.asp and `/registrazione.asp` reviewed;
  privacy terms cover personal-data processing. No explicit open data license or
  permission to republish the database was found. Footer reserves copyright.

This integration supports local, low-volume factual lookup with attribution and
links, not database replication. It retains no descriptions, photographs, agency
contacts or response bodies. This is an access assessment, not a claim of an open
license. Reassess terms before any hosted/public republication or bulk harvesting.

## Routing and scope

Packaged province routes are the actual homepage links, joined to GeoNames province
codes. Nearby gazetteer towns within radius + 20 km select provinces (nearest first,
max 3); this is a routing heuristic, not polygon coverage. Sparse settlements and
province changes can cause omissions. Only the residential catalogue is currently
integrated (including garages). Commercial/land/industrial catalogue expansion
remains outstanding. `location_search=false`: no upstream point/radius API.

Default max 2 pages per selected province and max 12 detail requests total. Source
order is relevance, so a small geographic radius can miss nearby listings beyond
these caps. Advertise incomplete coverage on every search; report caps, repeated
pages and record errors. Validate next links against the original catalogue path
and query. A recognized zero count is empty; missing layout/count is SourceChanged.

## Normalization

Only detail `Contratto=Vendita` accepted; sold/withdrawn/expired status excluded.
Current public sale advertisement establishes advertised availability, not legal
verification that the property remains available. Generate a factual title from
Tipologia + Comune; use numeric URL ID (not agency reference). EUR asking price
only with explicit euro marker. `Superficie` is m²; `Camere` is bedrooms, not Vani.
Missing optional numbers are null; malformed numbers warn. Taxonomy explicitly
maps residential forms and garages; unknown types are other.

Coordinates from the detail property map are approximate, never exact. Missing
maps fall back to a labeled GeoNames municipality point (`area_only`) or unknown;
strict engine excludes those. No address geocoding or agent-office coordinates.
Source date retained separately, UTC retrieval timestamp generated by Listing.

Synthetic fixtures reproduce structural markers only. Live testing is opt-in.
